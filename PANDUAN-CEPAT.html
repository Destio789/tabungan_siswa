SAKUSISWA · PANDUAN CEPAT

Siapkan aplikasi tabungan
untuk sekolah Anda.

HTML, CSS, dan JavaScript untuk GitHub Pages. Database dan login email/password menggunakan Supabase.

1. Pasang database

  1. Buat proyek Supabase baru.
  2. Buka SQL Editor, salin seluruh isi supabase/schema.sql, lalu jalankan satu kali.
  3. Aktifkan login Email, sign-up, dan email confirmation. Siapkan SMTP untuk konfirmasi email/password reset.

2. Isi konfigurasi

Edit config.js: isi supabaseUrl dan supabaseKey menggunakan Project URL dan publishable/anon key. Sesuaikan nama sekolah dan tahun ajaran.

Jangan menaruh service_role/secret key atau password database di HTML, JavaScript, maupun GitHub.

3. Daftarkan admin

Edit email/nama di supabase/admin-pertama.sql, lalu jalankan di SQL Editor. Admin memilih Aktivasi akun baru di website dengan email yang sama, membuat password, mengonfirmasi email, lalu login.

4. Upload ke GitHub

  1. Upload isi folder paket ke root repository. Pastikan index.html berada di root.
  2. Buka Settings → Pages → Deploy from a branch, pilih main dan / (root).
  3. Di Supabase, isi Site URL dan Redirect URLs dengan URL GitHub Pages Anda, termasuk nama repository.

5. Mulai gunakan

  • Admin: tambahkan wali kelas pada menu Pengguna.
  • Wali kelas: tambahkan siswa atau impor template CSV. Pilih siswa, waktu WIB, jumlah, dan keterangan transaksi.
  • Pengguna baru: aktivasi akun menggunakan email yang telah didaftarkan sekolah, lalu konfirmasi email.
  • Siswa: hanya melihat saldo dan riwayatnya sendiri.
  • Admin: dapat membatalkan transaksi dengan alasan dan menonaktifkan akun; catatan historis tetap disimpan.

Mencoba sebelum menghubungkan database

Jalankan python3 -m http.server 8080 dalam folder paket. Buka http://localhost:8080/ dan pilih Coba mode demo. Beralih peran akan mengulang data demo.

Untuk petunjuk lengkap, batasan, dan langkah pengujian, baca README.md. SQL/RLS dan login email belum diuji pada proyek Supabase Anda; jalankan tes database setelah konfigurasi.
